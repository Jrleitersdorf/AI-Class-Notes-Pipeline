## Statuses

- **PLANNED** — scope sketched; work not started. Spec may live as bullet points only.
- **IN PROGRESS** — currently being built. The spec is *living*; edit freely.
- **FROZEN** — shipped. The spec is a historical record and is **not edited** further. Corrections go in a new ADR or the next version's spec.

## Subversions

Minor versions (v2.1, v2.2, …) get their own spec file (`v2.1.md`) **only when work on that subversion begins**. Don't pre-plan 2.1 / 2.2 / 2.3 all at once — you'll rewrite them. Pick the next slice from [`ROADMAP.md`](../ROADMAP.md) when you reach that cut.
