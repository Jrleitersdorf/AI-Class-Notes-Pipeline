# V1 — "Working pipeline"

## Goal

Replace the old WorkOS / Supabase internal-API pipeline with a clean REST-API-based tool that syncs Granola meeting notes to local Markdown files, organized per class. Usable as a library (`import granola_sync`) **and** via an optional Tkinter GUI.

## Scope (shipped)

- [x] `granola_sync` Python package (`src/granola_sync/`, src-layout) with a public API.
- [x] `GranolaClient`: paginated note listing, 429 retry, infinite-loop guard, folder discovery by fetching full note detail.
- [x] Folder ⟷ local path mappings persisted in `config.json`.
- [x] `.state.json` skip-unchanged tracker (note_id → updated_at).
- [x] Markdown output: title + date + folders + attendees + AI summary + full transcript.
- [x] LLM-friendly transcript formatting: lecture mode (prose paragraphs, no labels) vs conversation mode (merged same-speaker blocks with labels).
- [x] Filename sanitization including newlines / carriage returns / tabs.
- [x] Tkinter GUI with Setup / Mappings / Sync tabs.
- [x] `python -m granola_sync` entry point.
- [x] 76-test pytest suite.
- [x] README + `CLAUDE.md` developer documentation.

## Non-goals (deferred)

- Modern / beautiful GUI → V2.
- Downloadable `.app` / `.exe` → V2.
- Scheduled auto-sync → roadmap.
- Multi-account → roadmap.

## Constraints / invariants established here

- Library must remain usable without the GUI.
- `config.json` and `.state.json` default to the project root; overridable via `config_path=` / `state_path=` kwargs on any public function.
- API keys stored locally in `config.json`; no telemetry, no third-party server.
- **Public API surface (frozen in V1, must stay backward-compatible in V2)**:
  - Sync: `sync_all`, `sync_folder`, `sync_dry_run`
  - Mapping CRUD: `create_mapping`, `list_mappings`, `get_mapping`, `update_mapping`, `delete_mapping`
  - API key: `set_api_key`, `get_api_key`
  - Types: `GranolaClient`, `FolderSyncResult`, `NoteResult`, `GranolaAPIError`
- Granola API idiosyncrasies worked around:
  - `GET /v1/notes` summaries omit `folder_membership`; full detail required for folder discovery (tracked in [TD-001](../tech-debt.md)).
  - Infinite-loop guard: `hasMore=True` with empty `cursor` now breaks instead of spinning forever.
